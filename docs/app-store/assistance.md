# Yumi – Assistance

Une question, un problème ou une suggestion ? Écris-nous à
**mwdlabs.contact@gmail.com** : nous répondons en général sous 2 jours ouvrables.

## Questions fréquentes

**Je ne reçois pas le code de connexion.**
Vérifie le dossier Indésirables ou Promotions de ta messagerie, et l'orthographe de
l'adresse. Tu peux demander un nouveau code au bout d'une minute.

**Comment ajouter un membre à ma famille ?**
Onglet Famille → « Inviter quelqu'un » : la personne saisit le code à 6 chiffres dans l'app. Pour un
enfant sans adresse courriel : onglet Famille → « Ajouter un enfant sans courriel ».

**Comment quitter une famille ?**
Onglet Famille → touche ton profil → « Quitter la famille ».

**Comment supprimer mon compte ?**
Onglet Famille → « Supprimer mon compte ». Ton adresse et ton profil sont effacés
immédiatement. Si tu es le seul adulte de ta famille, la famille et ses données sont aussi
supprimées.

**Où sont hébergées mes données ?**
Au Canada (Toronto). Voir la [politique de confidentialité](https://mwdlabs.ca/yumi/confidentialite).
